# Hell Hound context

- Native **Rust**, Windows/Linux CLI for Call of Duty assets, primarily WaW. Original 0BSD implementation by owner decision; do not port GPL Greyhound code. Public layout facts may inform independently written decoders; do not claim a formal clean-room process.
- Build/test: `cargo build --release --locked --bins`, `cargo test --locked --all-targets`, `cargo clippy --locked --all-targets -- -D warnings`, `cargo fmt --all -- --check`. Optional `bash tools/check-blender.sh` needs Blender; its Python code is only a Blender-API test harness, never the extractor implementation. `python3 -m unittest discover -s tools -p 'test_*.py'` tests the launcher.
- `src/discovery.rs`: native Windows/Linux game detection, game picker, waiting, installation/archive discovery. No-argument launch (or `open`) runs the ratatui interface in `src/tui/`. Users normally do not enter IWD paths or PIDs; advanced overrides remain available. Recognizing a game's executable does NOT imply its format decoder works.
- `src/archive.rs`: safe ZIP/IWD catalog/raw extraction, exact/glob selection, folder routing, SHA-256 locks. `src/recipe.rs`: strict archive and weapon TOML jobs; data, not executable scripts. `src/main.rs`: the batch CLI, and the interface by default.
- `src/tui.rs` is the interface core, after tdl's `ritual.rs` but plain: `Grimoire` is the terminal and is drawn on only through the `unsafe trait Haunted` (`bewitch` draws a page, `consult` measures one); a `Ritual` is a screen or popup (`render`, `prompt(grimoire, key)` returning `Phase::{Render, Prompt, Return}`, `tick` about once a second, `invoke` runs it). Ctrl+C is the `Interrupted` error, unwinding everything; `main` exits 130. `tui/screens/` (games, menu, browser, export) and `tui/popups/` (dialog, message/status/report, prompt, legend, resize). Colors come only from the one hard-coded `theme::THEME` (zombies palette), by role; no quips.
- Export problems the user can work around are `weapon::Problem`s, sent to the `ask` callback of `weapon::export`/`gltf::encode`: the interface asks (`Dialog::should_continue`), the batch commands answer from their flags (`main.rs`'s `answer`). Never turn one into a silent skip.
- `src/live.rs`: bounded read-only process memory and stock WaW SP/MP pool inspection/validation. `src/weapon/`: independent model/animation/IWI decoding and embedded skinned/animated GLB export. See README and `docs/WAW_LAYOUT.md` for supported formats and limitations.
- Owner's goal is complete Blender weapons: geometry, skin, rig, hands, textures and animations. A synthetic exporter/importer test is NOT real WaW compatibility proof. Live game export remains unverified. Reject delta/root-motion, unknown layouts, incompatible rigs and unsupported image formats explicitly; missing bones and textures are asked about (see `Problem`), never silently dropped. Packed normal/specular images are preserved but not automatically remapped to PBR.
- Keep deterministic ordering, archive overlay precedence, required-name checks, source read-only handling, portable path validation, no-clobber behavior, lock preflight and failure diagnostics. Never write game memory or change ptrace policy, privileges, game binaries/profiles or Steam settings automatically.
- `waw-zombies.py` (the Steam launcher, standard-library Python by owner request) and `tools/test_waw_zombies.py` are local and gitignored until the launcher works in game; never commit them. Its findings so far are in `secrets/TODO.md`. God is a toggle; never blindly repeat it.
- `secrets/`, `published/`, `output/`, `target/` stay local/untracked. Never read tokens or commit/push without a request. Use `--opencode` for ChatGPT via OpenCode attribution. Backlog: `secrets/TODO.md`; workspace plan: `../TODO.md`.
